# Environment Awareness

A modern multi-page environmental awareness website designed to promote recycling, saving water, reducing pollution, and planting trees.

## Project Overview

This project is a responsive website built with plain HTML, CSS, and JavaScript. It includes dedicated pages for Home, About, Blog, and Contact. The UI uses a modern dark theme and includes subtle animations to create an engaging experience.

## Project Structure

```bash
environment-awareness/
├── index.html
├── about.html
├── blog.html
├── contact.html
├── style.css
├── script.js
├── README.md
```

## Features

- Responsive layout for desktop and mobile
- Multi-page navigation
- Modern environmental theme
- Animated hero, cards, and sections
- Contact form UI
- Clean and easy-to-edit code

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## How to Run

1. Download or clone the repository.
2. Open the folder in your browser.
3. Launch `index.html` directly or serve locally.

### Optional local server

```bash
python -m http.server 8000
```

Then open:

```bash
http://localhost:8000
```
